# Эхо последнего рассвета

Первая сюжетная глава для **Minecraft Java Edition 1.20.1 + Forge**.

## Что уже есть в этой версии

- При первом входе в мир рядом с мировой точкой появления создаётся древняя обсерватория.
- В обсерватории появляется последний Хранитель — отдельный NPC с собственной пиксельной текстурой.
- У Хранителя есть анимации ходьбы, движения головы, idle-покачивание и движение плаща.
- При первом разговоре игрок получает дневник обсерватории.
- В сундуке обсерватории лежат три осколка памяти; если принести их Хранителю, он выдаёт звёздный ключ.
- Добавлена отдельная вкладка предметов мода в творческом режиме.
- Атмосфера события поддержана частицами и звуками.

## Сборка через GitHub Actions

1. Распакуйте архив на компьютере.
2. Создайте новый репозиторий GitHub.
3. Загрузите **всё содержимое этой папки** в корень репозитория. В том числе папку `.github` — в ней находится workflow сборки.
4. Откройте вкладку **Actions**. Запустится задача **Build Forge Mod**. При необходимости нажмите **Run workflow**.
5. Когда сборка завершится зелёной галочкой, откройте её и скачайте artifact `echoes-of-last-dawn-1.0.0`.
6. Внутри скачанного artifact будет `.jar`. Поместите его в папку `.minecraft/mods`.

Для игры нужен Minecraft 1.20.1, Forge 1.20.1 и Java 17.

## Как начать сюжет

Создайте новый мир. При первом входе в Верхний мир рядом с мировой точкой появления появится обсерватория. Найдите Хранителя, поговорите с ним, заберите три осколка из сундука и вернитесь к нему.

**Важно:** структура создаётся один раз на мир и сохраняет этот факт в данных мира. Если вы уже заходили в мир до установки мода, для чистого вступления лучше создать новый мир.

## Исправление сборки

В текущей версии исправлены импорт `Heightmap` для Minecraft 1.20.1 и создание яйца призыва через `ModEntities.STORY_KEEPER.get()`. Также зарегистрированы атрибуты Хранителя (здоровье, скорость и дальность обнаружения), необходимые для корректного появления моба в игре.


## Исправление getHeight для Forge 1.20.1

В `ObservatoryGenerator` результат `LevelReader#getHeight(...)` обрабатывается как координата Y (`int`) и преобразуется в `BlockPos` с X/Z. Это соответствует API Minecraft 1.20.1 и устраняет ошибки компиляции `int cannot be converted to BlockPos`.
